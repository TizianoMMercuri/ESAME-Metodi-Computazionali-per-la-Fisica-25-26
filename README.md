# ESAME-Metodi-Computazionali-per-la-Fisica-25-26
Il file **"tramonti.py"** Consiste in uno script python gestito dalla libreria argparse.
Digitando **"python3 tramonti.py -h"** si mostrano le due possibilità: -I e -O.
- Scegliendo la prima opzione e digitando quindi **"python3 tramonti.py -I"** si entra in un menù interattivo che consente all'utente di scegliere inizialmente una stella tra quelle a disposizione e l'angolo (tra 0 e 90°). Successivamente viene mostrato un graifco in cui si notano gli effetti dello scattering allo zenith, all'orizzonte e in funzione dell'angolo scelto. Infine, viene mostrato un altro grafico che mostra l'andamento del flusso relativo in funzione dell'angolo che descrive la posizione del Sole rispetto allo zenith
- Digitando invece **"python3 tramonti.py -O"**, si entra nella parte dedicata all'Ozono, in cui anche in questo caso è presente lo stesso menù interattivo di prima ma, a differenza del primo, con la sola possibilità di mostrare un grafico in cui si combina lo scattering Rayleigh con l'assorbimento dell'Ozono.
